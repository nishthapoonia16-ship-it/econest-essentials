# EcoNest Essentials

Create a modern and attractive 3-page e-commerce website for a fictional brand called EcoNest Store.

Page 1 – Home

Modern hero section with brand name, tagline and attractive product images

Featured products section

Category buttons

“Shop Now” button that navigates to the Shop page

Add smooth hover effects and simple animations

Responsive design for mobile and desktop

Page 2 – Shop / Products

Display products in attractive cards with:

Product image

Product name

Price

Category

Rating

Add to Cart button

Search bar to search products

Category filter

Sort products by price

Page 3 – Cart / Dashboard

Create a simple cart dashboard where users can:

View all added products

Increase/decrease quantity

Remove products from cart

See subtotal and total price

“Proceed to Checkout” button

Show a simple order confirmation message after checkout

Main Working Functions

Make sure these functions actually work:

Add to Cart

Search Products

Filter/Sort Products

Update Quantity and Remove from Cart

Calculate Total Price Automatically

Design

Clean, premium and modern UI

Attractive but not overly complicated

Consistent typography and spacing

Smooth transitions and hover animations

Responsive layout

Use realistic sample products and product images

Add a navbar with Home, Shop and Cart

Show cart item count in the navbar

The website should be a fully functional frontend project, not just a static design. All navigation, buttons, search, filters, cart operations and price calculations must work properly.
